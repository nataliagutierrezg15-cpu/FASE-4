# Software FJ - Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto de la Fase 4 del curso Programación (213023_530) de la UNAD.

El programa maneja clientes, servicios (salas, alquiler de equipos y asesorías) y reservas sin usar base de datos, todo con objetos y listas. Tiene manejo de excepciones para que no se detenga cuando hay errores, y guarda los eventos y errores en un archivo de logs.

## Qué se aplicó
- Clases abstractas, herencia y polimorfismo (los 3 tipos de servicio calculan el costo a su manera).
- Encapsulación y validaciones en los datos del cliente y de los servicios.
- Excepciones personalizadas, try/except, else, finally y encadenamiento de excepciones.
- Registro de eventos y errores en el archivo system_software_fj.log.
- 27 simulaciones con casos válidos e inválidos.
